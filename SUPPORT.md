# Getting help

| I want to… | Go here |
|---|---|
| Learn how to install and use Klar | [Docs](https://klar-cloud.vercel.app/docs) and [docs/INSTALL.md](docs/INSTALL.md) |
| Fix a problem | [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md) |
| Ask a question or share an idea | [GitHub Discussions](https://github.com/MatiasV3B/klar-plugin/discussions) |
| Report a bug | [Open an issue](https://github.com/MatiasV3B/klar-plugin/issues/new/choose) |
| Report a missed attack or false positive | [Open a detection report](https://github.com/MatiasV3B/klar-plugin/issues/new/choose) |
| Manage my plan, API keys or devices | [Dashboard](https://klar-cloud.vercel.app/account) |
| Report a security problem | [SECURITY.md](SECURITY.md), **not** a public issue |

When you ask for help, tell us your OS, Node.js version and Claude Code or Codex version, and remove any secrets from what you paste. The more context you give, the faster we can help.
